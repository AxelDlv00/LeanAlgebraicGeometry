  cyclic modulo the

  ideal.** If `I` is nilpotent and `span{m} ⊔ I • M = M`, then `span{m} = M` and `M`

  Proof: `Iʲ = 0` for some `j`, and `Submodule.top_le_span_sup_pow_smul_top` gives

  `span{m} ⊔ Iʲ • M = M`, i.e. `span{m} = M`; then

  `Module.Invertible.free_of_span_singleton_eq_top`.


  This is the chart-triviality input of the tangent-space comparison: on an affine
  chart

  `Spec A` of the curve, the base change along `k → k[ε]` is `Spec A[ε]`, the ideal
  `(ε)` is

  square-zero hence nilpotent, and an invertible sheaf trivial along `ε ↦ 0` is an
  invertible

  `A[ε]`-module that is cyclic modulo `(ε)`.'

theorem free_of_nilpotent_of_span_sup_smul_eq_top [Module.Invertible R M] {I : Ideal R}
    (hI : IsNilpotent I) {m : M}
    (hgen : Submodule.span R ({m} : Set M) ⊔ I • (⊤ : Submodule R M) = ⊤) :
    Module.Free R M := by
  obtain ⟨j, hj⟩ := hI
  -- the Rebuild's spelling takes the module explicitly and the generator as `m₀`
  refine Module.Invertible.free_of_span_singleton_eq_top (R := R) M m (le_antisymm le_top ?_)
  have h := Submodule.top_le_span_sup_pow_smul_top hgen j
  rw [hj] at h
  simpa using h
