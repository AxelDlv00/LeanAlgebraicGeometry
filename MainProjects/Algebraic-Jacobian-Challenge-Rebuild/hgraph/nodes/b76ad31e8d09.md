def IsPlusHonest (T : Over (Spec (.of k))) (μ : picEt C T) : Prop :=
  ∀ U : T.left.affineOpens, ∃ z : relPic C (overSpec k Γ(T.left, U.1)),
    relPicToPicEt C (overSpec k Γ(T.left, U.1)) z
      = picEtMap C (Over.fromSpecAffine T U) μ

omit [SmoothOfRelativeDimension 1 C.hom] in

## Reviewer audit: the obstruction here is a DIRECTION, not a base shape

Answering `ajcr-p2` on conversation I-0926; board rows `AJCR.w4-rep.datum.dat-b` and
`…dat-c.c9-chartlocus.chart-u` updated (commit f272fe221).

The question asked was whether this hypothesis can be reduced to field points, since `chartLocus`
is pointwise via `Over.testPoint`. It cannot, and the reason is sharper than the "general
sectionless affine base" framing that preceded it:

* `chartLocus C m Z lam = {t | IsSplitWitness C (picEtMap C (Over.testPoint t) (chartTwist …))}`
  (`Pic0ChartLocus.lean:244-247`) is a predicate on the **image** of the class under `picEtMap`.
  Pushforward is functorial, so the passage to `κ(t)` is **free** (elaborated type at `:247`
  confirmed by LSP: `picEt C (overSpec k (Over.testPointField t))`);
* `IsPlusHonest` demands a **preimage** under `relPicToPicEt` at the ring `Γ(T.left, U)`.

Covariant versus contravariant. Knowing the fibre class lies in `relPic`'s image over the *field*
gives nothing at `A`: that would need the image to descend along
`relPic C (overSpec k A) → relPic C (overSpec k κ(t))`, i.e. a spreading-out.

**Measured absence** (not grepped): this predicate has exactly six declarations tree-wide — the
definition, `.mul`, `.inv`, `.pow`, `chartLocusOpensOfIsPlusHonest`, and its `mem_` lemma. None is
a spreading-out, a localisation statement, or a field-point reduction. The file carries zero LSP
diagnostics, so imports were current when this was measured.

**The bounded brick, if a lane wants one:** spreading-out for the *range* of `relPicToPicEt` along
a localisation `A → A_f`. Genuinely absent by the census above, self-contained, and the descent in
miniature — not cheap, but honestly stated. What is *not* worth a round is
general-affine-base → field-point: the missing direction is the descent.
