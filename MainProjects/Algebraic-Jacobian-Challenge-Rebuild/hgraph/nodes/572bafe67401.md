docstring: "**THE CHART PARAMETER *IS* THE FIBRE DEGREE OF THE TWISTED CLASS** — unconditionally,\
  \ for\nevery chart, with no hypothesis beyond `λ ∈ pic⁰`.\n\n`degAt_chartTwist`\
  \ gives `deg(chartTwist λ) = m·d₁ − deg Z`, and the chart's own legality\nhypothesis\
  \ `hdeg` says `deg Z = m·d₁ − n`.  Substituting cancels `m` and `d₁` entirely and\n\
  leaves `n`.\n\nThis is worth stating because it removes the last place the twist\
  \ data could be hiding a\nconstraint, and because it fixes where the fork is asked.\
  \  `chartLocus`\n(`Picard/Pic0ChartLocus.lean:244`) is by definition the locus where\
  \ the twisted fibre class has\nan **effective witness with vanishing `H¹`**; by\
  \ the rank anchor\n`h0_eq_deg_add_chi_of_subsingleton_hModule_one` such a witness\
  \ has\n`h⁰ = deg + χ = n + (1 − g)`.  So on `chartLocus`:\n\n* at `n = g` the witness\
  \ has `h⁰ = 1` and is therefore the *unique* effective representative of\n  its\
  \ class — the fork's **positive** branch, and the reason `Pic0ChartLocus.lean:194-201`\n\
  \  records `+g` as \"the unique degree at which the witness is unique\";\n* at `n\
  \ > g` it has `h⁰ = n − g + 1 ≥ 2`, so the linear system is positive-dimensional\
  \ and a\n  witness for the **negative** branch is what one expects to find.\n\n\
  Neither branch is proved here — `chartLocus` membership is a hypothesis about the\
  \ class, not a\ntheorem about the chart, and the `h⁰ = 1` reading is fibrewise while\
  \ the obligation is at a\ngeneral test (the caveat `Picard/Pic0ChartAbelNonInjective.lean`\
  \ states and I do not weaken).\nWhat is settled is that the question is **arithmetic\
  \ in `n` alone**: no chart parameter, no\ntwist exponent and no `Z` enters it.\n\
  \n**AND `n` IS NOT FREE, WHICH DECIDES WHICH BRANCH IS LIVE.**  `abelSigmaChart`\n\
  (`Picard/Pic0AtlasFromDivRep.lean:205`) takes `rep : (divFunctor C π n).RepresentableBy\
  \ D`, and\nevery producer of such a representation in the tree — `DivRepChartRange`,\
  \ `DivRepAffPullClause`\n(two), `DivRepGlobalClassify`, `DivRepKit` — carries the\
  \ hypothesis\n`hchi : χ(\U0001D4AA_C) = 1 − g` with **the same `g` as its `divFunctor`\
  \ index** (checked at each of the\nfive sites).  So a chart built on an actual representation\
  \ has `χ = 1 − n`, i.e. `n` *is* the\ngenus, and the case `n > g` cannot arise for\
  \ any chart the atlas can contain.\n\nThat is the useful consequence and it points\
  \ at the **positive** branch: on `chartLocus`, at the\nonly degree a chart can be\
  \ built at, the fibre witness has `h⁰ = 1` and is unique.  It does not\nclose the\
  \ fork, because uniqueness of the *fibre* witness is not injectivity at a general\
  \ test —\nand `Pic0ChartAtlasParamFree.lean` is precisely the observation that the\
  \ atlas may be\nheterogeneous in `n`, which this remark constrains rather than contradicts\
  \ (each index still\ncarries its own `rep`, hence its own `hchi`, hence `nn i =\
  \ g` for every `i`)."
