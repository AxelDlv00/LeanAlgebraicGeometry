For a \(k\)-rational point \(P : \Spec k \to C\), the \emph{Abel--Jacobi map}
  \(\varphi_P : C \to \Jac(C)\) sends a point \(Q\) to the class of the line bundle
  \(\struct C(Q - P)\).
