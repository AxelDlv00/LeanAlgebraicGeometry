If a test `T` has a point `t` and a section `s`, `hcov` demands a chart point
`x : W ⟶ (D i).left` with range inside `range ((⊥).ι.base) = ∅`, plus `t ∈ W`.
So `W` is nonempty and `x.base`'s range is empty — contradiction. -/
