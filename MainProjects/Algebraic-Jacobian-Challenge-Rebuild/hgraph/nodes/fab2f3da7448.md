docstring: '**`ChartsCoverLocally` gives back an open cover on whose members a chart
  hits `s`.**


  The converse direction, and the check that the pointwise hypothesis above is the
  right one.

  From the sieve condition one extracts a Zariski cover of `T` by `mem_grothendieckTopology_iff`

  and reads the supremum membership at each cover map.


  **The one honest difference**, and it is why this is stated with a general `Y ⟶
  T` rather than

  an open of `T`: `mem_grothendieckTopology_iff` returns a cover by *arbitrary* schemes
  with

  open-immersion maps, not by opens of `T`.  Those are the same up to isomorphism

  (`Scheme.Hom.isoOpensRange`) but not on the nose, so the converse produces a cover
  map where

  the hypothesis consumed an opens inclusion.  For the purpose this serves — showing
  the

  pointwise data is *available*, hence not a hypothesis chosen for provability — a
  cover map is

  exactly as good, and pretending otherwise would need a transport that adds nothing.'

theorem pointwise_of_chartsCoverLocally {ι : Type u} {X : ι → Scheme.{u}}
    (f : ∀ i, yoneda.obj (X i) ⟶ (pic0SigmaSheaf C).1)
    (h : ChartsCoverLocally C f) (T : Scheme.{u})
    (s : (pic0SigmaSheaf C).1.obj (op T)) :
    ∃ (𝒰 : T.Cover.{u} (Scheme.precoverage @IsOpenImmersion)),
      ∀ j : 𝒰.I₀, ∃ (i : ι) (x : 𝒰.X j ⟶ X i),
        (f i).app (op (𝒰.X j)) x = (pic0SigmaSheaf C).1.map (𝒰.f j).op s := by
  obtain ⟨𝒰, hle⟩ := Scheme.mem_grothendieckTopology_iff.mp (h T s)
  refine ⟨𝒰, fun j => ?_⟩
  have hj := hle (𝒰.X j) (𝒰.f j) (Presieve.ofArrows.mk j)
  rw [iSup, Sieve.sSup_apply] at hj
  obtain ⟨S, ⟨i, rfl⟩, x, hx⟩ := hj
  exact ⟨i, x, hx⟩
