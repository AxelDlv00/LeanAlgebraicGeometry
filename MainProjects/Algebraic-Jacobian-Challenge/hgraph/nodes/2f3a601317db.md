If \(N' \le N\) and \(x\) preserves \(N\) (\(x \cdot N \subseteq N\)), then
  \(N' + x \cdot N \le N\): both summands lie in \(N\). Hence the cokernel pair
  \((N,\, N' + x \cdot N)\) is a valid subquotient pair
  (\cref{def:graded_subquotientHilb}).
