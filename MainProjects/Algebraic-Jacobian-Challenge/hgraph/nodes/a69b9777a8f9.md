If $\mathcal N$ is a locally trivial $\mathcal O_T$-module of rank one, define
  \[
    \pi_T^*\mathcal N
      :=\bigl((\pi_T)^*\mathcal N,\;\text{the local-triviality witness
         supplied by pullback preservation}\bigr)
      \in \mathrm{OnProduct}(C\to S,T\to S).
  \]
  On isomorphism classes this is the usual pullback operation on line bundles.
