docstring: "**The Hom-side of the descent goal, with the curve in the conclusion.**\n\
  \nFor a smooth proper curve `C` over an **arbitrary** field `k`, a field extension\n\
  `k'/k`, a `k'`-scheme `X'` **representing** `picEt (C_{k'})`, a semilinear\n`Gal`-action\
  \ on `X'.left`, and a `k`-scheme `Y` that is its Galois quotient: there\nis a map\n\
  \n```\nHom_{Over (Spec k)}(T, Y)  ⟶  picEt (C_{k'}) (T_{k'})\n```\n\nfor every `k`-test\
  \ `T`, factoring as a **bijection** onto `Γ`-equivariant\nmorphisms followed by\
  \ the representation's `homEquiv`. This is the statement the\nseam's four-input\
  \ paragraph (`Picard/FGAPicRepresentability.lean:475`) lists\nantecedents *of*,\
  \ on its Hom side, and it is the shape the descent step must\nupgrade.\n\n**Exactly\
  \ which half is owed.** The first leg is a bijection\n(`homEquiv_equivariant_of_galoisQuotient`,\
  \ from `IsGaloisQuotient` clause 3) and the\nsecond leg is **injective** (`equivariantToClass_injective`),\
  \ so the whole composite\nis injective (`homClassMap_of_galoisQuotient_injective`).\n\
  \nWhat is owed is **not** \"the characterisation of the image\". That sentence stood\
  \ here\nand is **withdrawn** (`I-1418`, `I-1421`): `range_equivariantToClass` characterises\n\
  the image outright, with no invariance input, and\n`surjective_equivariantToClass_of_subsingleton`\
  \ shows the leg can even *be*\nsurjective. What is owed is the narrower **predicate\
  \ match** — that\n\"`rep.homEquiv.symm c` is `Γ`-equivariant as a morphism\" agrees\
  \ with \"`c` is a\n`Γ`-invariant `picEt`-class\" — which is `G1`, roadmap\n`AJC.picrep.etale-rep.invariance`\
  \ (held by `ajc-p1` as of `I-1417`; `ajc-p2`\nreleased it).\n\nDo **not** read this\
  \ as a representation of `picEt C`: it is an injection into the\nclasses of the\
  \ base-**changed** curve, and even a bijection onto the invariants would\nstill\
  \ need the amalgamation of `Picard/EtaleFieldCover.lean` to descend to\n`picEt C\
  \ (T)`.\n\n**Three things this does not do.**\n* It does not close or weaken `Scheme.fgaPicardRepresentability`,\
  \ which is used in\n  this file's verification only as a `sorryAx` control.\n* `rep`\
  \ is a **hypothesis**, the campaign's undischarged output; field 1 of clause\n \
  \ (1) is witnessed for no curve, so nothing here is instantiable at a curve today.\n\
  * It carries no `HasRationalPoint` binder (`I-0491`), and no separability or\n \
  \ finiteness hypothesis on `k'/k` — none is used."

noncomputable def homClassMap_of_galoisQuotient
    (C : Over (Spec (CommRingCat.of k)))
    [SmoothOfRelativeDimension 1 C.hom] [IsProper C.hom]
    {X' : Over (Spec (CommRingCat.of k'))}
    (rep : (PicScheme.picEt (Scheme.baseChangeField C k')).RepresentableBy X')
    (ρ : AlgebraicJacobian.GaloisDescent.SemilinearGalAction k k' X'.left X'.hom)
    {Y : Over (Spec (CommRingCat.of k))}
    (hq : AlgebraicJacobian.GaloisDescent.IsGaloisQuotient ρ Y.hom)
    (T : Over (Spec (CommRingCat.of k))) :
    (T ⟶ Y) → (PicScheme.picEt (Scheme.baseChangeField C k')).obj
      (Opposite.op (PicScheme.baseTest (k' := k') T)) :=
  fun φ => equivariantToClass C rep ρ T
    ((homEquiv_equivariant_of_galoisQuotient ρ hq T).some φ)
