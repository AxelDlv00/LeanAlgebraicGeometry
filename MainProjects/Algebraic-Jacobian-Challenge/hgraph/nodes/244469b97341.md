For fixed $C\to S$ and $T\to S$, define
  \[
    \mathcal L\sim\mathcal L'
      \quad\Longleftrightarrow\quad
      \mathcal L.\mathrm{carrier}\cong\mathcal L'.\mathrm{carrier}.
  \]
  This is an equivalence relation on
  $\mathrm{OnProduct}(C\to S,T\to S)$, and the quotient set
  \[
    \mathrm{LB}(C\times_S T):=
    \mathrm{OnProduct}(C\to S,T\to S)/\!\sim
  \]
  is the set of isomorphism classes of line bundles on $C\times_S T$.  The
  canonical projection onto this quotient is surjective.
