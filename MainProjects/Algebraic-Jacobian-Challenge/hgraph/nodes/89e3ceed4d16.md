If the graded Hilbert function \(h_{\mathcal{F},s}\) is a rational Hilbert
  function of some order \(d\) (\cref{def:ratHilb}), then the Hilbert
  polynomial \(\Phi_{\mathcal{F},s}\) of \cref{def:hilbert_polynomial}
  satisfies \(\Phi_{\mathcal{F},s}(m) = h_{\mathcal{F},s}(m)\) for all
  \(m \gg 0\).
