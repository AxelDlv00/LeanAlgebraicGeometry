\chapter*{About This Blueprint}
\label{universal-p-adic-gross-zagier-formula-about}

This project follows \emph{The universal p-adic Gross--Zagier formula} by Daniel Disegni (2022). The
retrieved source is archived under
\href{../../../../../references/universal-p-adic-gross-zagier-formula/}{\texttt{universal-p-adic-gross-zagier-formula}} and is indexed in
the workspace reference manifest. The corresponding preprint is
\href{https://arxiv.org/abs/2001.00045}{arXiv:2001.00045}.

The setup contains Hilbert modular forms, unitary Shimura varieties, Heegner cycles, Bloch--Kato Selmer groups, and $p$-adic height pairings varying in Hida families. Local toric periods and multiplicity one construct the global pairing; universal Heegner classes and sheaves on eigenvarieties interpolate the classical data.

This blueprint is an independently worded, source-faithful mathematical
outline of the paper's definitions, constructions, and principal results. It
should be read alongside the original source; the source anchor on each node
points to the complete extracted TeX. Statements are intentionally marked
\notready until a matching Lean declaration and proof have been added.

\begin{theorem}[Universal p-adic Gross--Zagier identity]
\label{universal-p-adic-gross-zagier-formula-main}
\source{universal-p-adic-gross-zagier-formula}
\uses{universal-p-adic-gross-zagier-formula-setup}
The derivative of the universal $p$-adic $L$-function at the central critical point equals the universal $p$-adic height pairing of the corresponding Heegner classes, with the normalization specified in the paper.
\notready
\end{theorem}
