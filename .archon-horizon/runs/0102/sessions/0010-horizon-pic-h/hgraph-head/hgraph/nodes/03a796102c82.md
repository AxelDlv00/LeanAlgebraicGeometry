docstring: "**The representative-level overlap compatibility at bare systems**: over\
  \ each overlap carrier\n`T i j` the two pulled systems are divisor-equal.  The chart-typed\
  \ `AwayCompatDivEq` spells the\npulled systems as `adaptation.pulledEquations`,\
  \ i.e. as `pullback` at the regularity the\nCERTIFICATE supplies; a bare system\
  \ carries no certificate, so the regularity witnesses travel\nwith the hypothesis.\n\
  \nThey are **existentially** bound.  A predecessor draft of this docstring justified\
  \ that by\nclaiming the `∀ hi hj, DivEq …` spelling \"would be vacuous the moment\
  \ one of the two\n`PullRegular`s happened to be uninhabited\".  **That justification\
  \ is false and was refuted by\nelaboration** (reviewer pass, run 0070 s0010; inbox\
  \ `I-0643`).  The two spellings are equivalent\nwherever this file is instantiated:\n\
  \n* `∃ ⟹ ∀` holds unconditionally, because `regular` is a `Prop` field and so\n\
  \  `d.pullback f h₁ = d.pullback f h₂` by `rfl`;\n* `∀ ⟹ ∃` holds whenever both\
  \ legs are open immersions, by\n  `pullRegular_of_isOpenImmersion` above — and every\
  \ instantiation in this tree puts the overlap\n  carrier at an away localization,\
  \ where both legs *are* open immersions\n  (`isOpenImmersion_relCurveMap_away`).\n\
  \nSo the vacuity scenario cannot arise here, and a vacuity argument of that shape\
  \ is\n**carrier-relative**: it must be checked where the side condition is actually\
  \ instantiated, not\nin the abstract (inbox `I-0644`).\n\nThe real reasons to keep\
  \ the `∃` form, which are the ones to quote: the *producer* has the\ncertificate's\
  \ own regularity witnesses in hand and should not have to prove the general\nstatement,\
  \ and the *caller* need not know its legs are immersions in order to state the\n\
  hypothesis.  It is also the stronger form, so nothing is lost."
