If a map of pairs \(f : P \to P'\) is surjective on all three carriers, then
  \[
    0 \longrightarrow K(f) \longrightarrow P \xrightarrow{\ f\ } P' \longrightarrow 0
  \]
  is a short exact sequence of two-lattice pairs.
