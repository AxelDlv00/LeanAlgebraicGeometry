For \(g \in K(X)^\times\), the set of closed points at which \(g\) has nonzero order,
  \(\{ x : \mathrm{ord}_x g \neq 0 \}\), is finite. (Here \(X\) is additionally assumed
  quasi-compact over \(K\), so that its underlying space is Noetherian.)
