  geometrically irreducible curve `C/k` there is a finite `k`-morphism `π : C ⟶ ℙ¹`.\n\
  \nThis is the keystone the two-lattice finiteness argument for `H¹(C, \U0001D4AA\
  _C)` consumes.\n\nProof route (see `informal/route-decision.md`, Wave 1 item 4):\n\
  1. `C` is integral (smooth ⟹ geometrically reduced, `AlgebraicJacobian.Curve.\n\
  \   GeometricallyReduced`, plus geometric irreducibility, `AlgebraicJacobian.Curve.Basic`),\n\
  \   and the function field of `C` contains an element transcendental over `k`: the\
  \ étale\n   coordinate of a standard smooth chart of relative dimension `1`\n  \
  \ (`SmoothOfRelativeDimension.exists_transcendental_functionField`, via the structure\n\
  \   theorem for standard smooth algebras of Stacks 00T7);\n2. the transcendental\
  \ function spreads out to a morphism `π : C ⟶ ℙ¹` over `k`: the stalks\n   of `C`\
  \ are valuation rings (localizations of the Dedekind chart rings,\n   `AlgebraicJacobian.Curve.DedekindSections`\
  \ and `Curve.StalksDVR`), so at each point\n   either `f` or `1/f` is a regular\
  \ germ; the two chart morphisms agree generically by the\n   gluing identity `P1.fromSpecChart_units`,\
  \ so the associated rational map `C ⤏ ℙ¹` is\n   defined everywhere (`AlgebraicJacobian.Curve.RationalToP1`);\n\
  3. `π` maps the generic point to the generic point (transcendence again), hence\
  \ has finite\n   fibers on the height-one Noetherian space `C`, hence is locally\
  \ quasi-finite;\n4. conclude with `exists_isFinite_toP1_of_locallyQuasiFinite` (Zariski's\
  \ main theorem)."
