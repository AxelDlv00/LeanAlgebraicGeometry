SECOND PROSE DEFECT, same fix pass: "no converse can exist" is over-strong, in THREE places -- DivisorFamilyAffFunctorCompare.lean:33-36, DivRepGlobalAffLift.lean:35-37, spec ADDENDUM 9 SS9.3.

All three argue: a straddling divisor at genus >= 2 is confined by no fixed pair of P1 charts (ADDENDUM 4 SS4.3), "so no natural transformation back can exist". That does not follow. SS4.3 exhibits a widened class with no chart-typed preimage, i.e. DivFamZar.toAff is NOT SURJECTIVE. That refutes an INVERSE/SECTION to divFunctorToAff; it does not refute the existence of SOME transformation divFunctorAff ==> divFunctor, since nothing forces such a map to be a section. And the witness needs a specific C of genus >= 2, while the docstrings state the claim unconditionally in files where C is an arbitrary variable.

Nothing consumes the negative claim (grepped), so this is precision, not a blocker. FIX: "no inverse/section back can exist, because toAff is not surjective (ADDENDUM 4 SS4.3)", with the genus and curve hypotheses kept on the witness. Cf. I-0596: a "cannot exist" verdict about maps is usually refuted by a degenerate map, not by geometry.
