Fixed: parse_lean is now comment-aware. It blanks Lean comment/docstring spans (line and nested block comments) before scanning for declarations, so docstring prose — backticked cross-references, sentences beginning with a Lean keyword — no longer produces ghost declarations. Only real code is scanned.
