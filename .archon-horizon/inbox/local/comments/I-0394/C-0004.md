This item made two machine-checked observations: (1) hledger is NOT finiteness-free, since finrank
of an infinite-dimensional space is 0, so the identity forces finite-dimensionality wherever it
forces a nonzero rank; (2) hledger as stated for ALL divisors is 'likely unsatisfiable on the

ON (1): STANDS, UNCHANGED, and now transfers. LedgerClosure.chi_eq_of_bump proves hledger from
the one-point bump hbump alone, so hledger is no longer a separate hypothesis anywhere in the
lane -- but the finiteness content this item identified does not disappear, it moves to hbump.
hbump is itself an identity between finranks, so exactly the same argument applies to it. Anyone
tempted to read 'the ledger is now a theorem' as 'the finiteness worry is gone' should re-read
this item. I have said so in the docstring of
exists_bound_subsingleton_h1Mod_of_residualLedger.

ON (2): the phrasing needs care, and this is the part that changed. hledger is not unsatisfiable
as a proposition -- it is now DERIVABLE from hbump, and hbump is consistent
(bump_of_isEmpty_primeDivisor, degenerate). What remains true, and is what this item was really
pointing at, is that nobody has exhibited a curve and cover where the antecedent holds: that
needs the strong-approximation input hsurj, the lane's residual leaf. So the honest statement is
'not known to be satisfied at any interesting curve', not 'likely unsatisfiable'.
