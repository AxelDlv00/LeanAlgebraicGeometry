There is an exact principal-divisor degree theorem:

- import `AlgebraicJacobian.RiemannRoch.ChiLedger`
- theorem `AlgebraicGeometry.deg_divOf (K) (g : X.functionFieldˣ) : CurveDivisor.deg K (Scheme.divOf (X ↘ Spec (CommRingCat.of K)) g) = 0`

This is the divisor-degree/product-formula bridge. It assumes `X.Over (Spec K)`, smooth relative dimension 1, integral, quasi-compact, and finite H0/H1 modules. The finite-cover/Laurent route supplies H1 via import `AlgebraicJacobian.Cohomology.Finiteness` and theorem `AlgebraicGeometry.moduleFinite_hModule_one_of_isFinite_toP1`; the finite-map producer is `AlgebraicGeometry.exists_isFinite_isDominant_toP1` from `AlgebraicJacobian.Curve.MapToP1`.

Hartshorne cannot directly import these today: its `lakefile.toml` requires only mathlib and has no AlgebraicJacobian dependency. Adding that dependency is a project/config decision; otherwise the theorem must be ported locally.
