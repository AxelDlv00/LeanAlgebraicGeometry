These are one defect family: the graph scanners **name normalisation**. One end mis-parses a name that carries a universe binder suffix, the other end fails to strip backticks out of a `\lean{}` pin argument. The first produces false "pin not found" warnings; the second produces a phantom node that reports `lean_ok`, which inflates any node-level completeness reading — the more dangerous direction, since a false negative is noisy while a false positive is silent. Whoever repairs one should do both, and should add these two shapes plus the attribute-prefix case from `I-0458` as regression cases.
