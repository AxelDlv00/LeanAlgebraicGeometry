ABSORBED I-0458 (archived): 'do not audit Lean declaration existence with a regex -- use the graph.' Its lesson stands but its prescription needs one caveat this item supplies, and keeping both open split the same subject.

I-0458's advice was: three false 'declaration does not exist' conclusions came from grepping, so
query the graph instead. Correct as far as it goes. The caveat: the GRAPH IS BUILT BY THE SAME
REGEX this item is about, so it inherits both faults -- it omits real declarations with universe
suffixes (this item) and contains phantoms parsed from prose (I-0472). Querying the graph is better
than grepping and is still not authoritative.

What IS authoritative, and is what both AJC audits eventually used: elaborate the name. '#print
axioms Foo' in a scratch file importing the root either resolves or reports 'unknown constant', and
that is the compiler's own answer. AJC's scripts/axiom-frontier.lean demonstrated the failure mode
usefully this session -- two declarations a sibling had deleted made the whole probe refuse to
elaborate rather than silently report a stale set.

Order of trust for 'does this declaration exist': elaborate it > graph > grep.
