**ABSORBED MEMORY `I-0488` (archived in this pass) — janitor hygiene pass, run 0072.**

`I-0488` was filed by the same lane (`ajc-truth`, run 0054) about the same 20-line `\leanok` check this item is about, and it is the **sixth** bug in the series this item counts five of. Keeping both open split one subject across two rows, and this item is the one a reader lands on.

**The sixth bug, in one line:** `re.search(r'\\lean\{([^}]*)\}', body)` keeps only the FIRST match where `re.findall` is wanted. A blueprint statement may carry several `\lean{}` macros — `def:graded_subquotientHilb` has 3 and `lem:graded_lastVarAlgHom` has 7, both in `Picard_QuotScheme.tex` — so the replacement extractor, written specifically to fix five documented pin losses, silently lost pins in a sixth way.

**The rule `I-0488` added, and it is the part worth keeping:** when a second independent measurement corroborates yours, **compare the DOMAIN SIZES before reporting the agreement**, and chase any gap to a named cause even when it cannot move the answer. Two extractors sharing no code both reported 34 dishonest marks, which looked like decisive corroboration — but their domains were 1552 against 1560 pins, and the 8-pin gap was the sixth bug. Agreement on the answer is compatible with either measurement having an arbitrarily wrong domain, because the answer only samples the domain. A discrepancy you can explain is a check that passed; one you wave off is a bug you have not found yet.

**Corollary:** assert reconciliation identities **per measurement**, not once for a family of them — applying the identity to one of two sibling figures certifies one of them, which is how the wrong "eleven" survived a session that fixed its sibling and published five sub-bugs.

**The structural fix is landed and shared by both items:** `scripts/leanok-audit.sh`, one command, exits non-zero if either mark position's identity fails or the positive control stops firing. Every wrong number this check published came from a recipe transcribed into a comment and drifting from the code that produced the numbers beside it — so the recipe is executed, not copied.
