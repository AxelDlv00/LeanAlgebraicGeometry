ABSORBED MEMORY `I-0399`, which I archived in the same pass; this item is now the single home of the "named-leaf factorisation compiles but is not what you think" family (janitor hygiene pass, run 0053 s0004).

`I-0399` ("Checking hypotheses load-bearing individually is not enough: check whether their CONJUNCTION is equivalent to the goal", `ajc-rr` run 0055, `Adelic/BoundedVanishing.lean`) is the **opposite failure of the same technique**. This item covers the leaf that is too *strong* — extracted without its enabling hypotheses, hence false, hence the assembly is vacuously true. `I-0399` covers the leaf set that is too *weak* — each hypothesis genuinely load-bearing, `lean_minimal_hypotheses` clean, and yet the conjunction provably equivalent to the conclusion, so the "reduction" is a re-indexing. Both compile; both print `[propext, Classical.choice, Quot.sound]`. One memory, two directions.

**Add to the checklist above, as steps 4 and 5:**

4. **Try to prove the conjunction of the hypotheses FROM the conclusion** (or from the conclusion restricted to the subfamily where they are stated). If that succeeds, the theorem is a re-indexing, not a reduction — say so in the docstring rather than reporting it as a gap closed. *Instance:* `hbase ∧ hpeel` is provably equivalent to $\forall D' \ge D_0,\ \mathrm{Subsingleton}(\check H^1(D'))$, because `hpeel` follows from cone-vanishing by taking $y = 0$ in the concrete criterion — and that equivalence is now itself a landed theorem, `coneVanishing_iff_base_and_peel`, which is the honest way to publish it.
5. **"Finiteness-free" is a claim about instance arguments only.** A hypothesis of the shape $\forall D,\ \chi(D) = \chi(0) + \deg_k D$ looks finiteness-free and is not: `Module.finrank` of an infinite-dimensional space is `0`, so such an identity forces finite-dimensionality wherever it forces a positive rank. Stating a conclusion with `Subsingleton` avoids the *instance*, not the *content*.

Those three plus this one are the same lesson at four altitudes.
