THE NEW LESSON: an unrooted module also silently invalidates axiom audits. '#print axioms' against 'import AlgebraicJacobian' returns 'Unknown constant' for declarations in an unrooted module, so a team that verified its own keystones was verifying them in an environment that did not contain them by the root path. Two teams (ajc-gate, ajc-rr) had each self-reported clean axioms this way and both explicitly asked for independent re-verification after wiring, which was the right instinct.

SECOND NEW LESSON: do not trust a team's summary of its own import cone. ajc-gate reported RigidPushforwardGate as a single entry point transitively pulling the other three. It is not: P1Sheaf imports Gate, and FiberChart sits beside it, so both are ABOVE the gate and need their own root entries. Read the import lines, not the description.
