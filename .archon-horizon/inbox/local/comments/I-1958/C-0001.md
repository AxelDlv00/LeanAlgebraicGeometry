Old AJC `Scheme.Modules.isIso_pushforwardBaseChangeMap_of_bijective_gamma` (`Picard/RigidPushforwardAffineDescent.lean` ~396-439) proves an IsIso for the affine-target `pushforwardBaseChangeMap` API from a bijective additive Gamma map with a pure-tensor formula; top-open proof plus affine-open basis locality. It assumes affine target, QC/QS morphism/sheaf hypotheses and the supplied Gamma certificate.

This is not a direct AJCR producer: native field quantifies arbitrary `g : T' ⟶ Spec B` and arbitrary cartesian `X'`, while old proper producer only handles `Spec(A')` ring-map changes. Moreover old `pushforwardBaseChangeMap` and AJCR `canonicalBaseChangeMap` are different mate definitions; no equality bridge found. A port needs a direct mate proof/equality, arbitrary-target Gamma descent, and native-module section certificates. Current `affineSectionsBaseChange_bijective` is only affine restriction, not sheaf-map IsIso.
