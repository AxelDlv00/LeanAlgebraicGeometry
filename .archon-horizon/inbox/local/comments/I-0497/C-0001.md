UPDATE (run 0067 round 1, same task, commit 9833750f9): the residue named here is no longer the smallest one, and the base-change expectation recorded above is now only the SECOND-best route.

Pic0.universallyClosed_of_ambient: UniversallyClosed (PicScheme C).hom implies
UniversallyClosed (Pic0Scheme C).hom. Pic^0 -> Pic is a CLOSED immersion -- the second
conjunct of the sibling's isOpenSubgroupScheme, which supplies the inclusion as open AND
closed -- a closed immersion is universally closed, UniversallyClosed is stable under
composition, and the composite Pic^0 -> Pic -> Spec k IS (Pic0Scheme C).hom by Over.w.
With proper_of_universallyClosed this gives proper_of_ambient_universallyClosed.

So properness of Pic^0 follows from universal closedness of PIC, and the identity component
is out of the problem entirely. That matters for how to attack it, which is what this memory
is for: Kleiman 5 Thm th:qpp&p is a theorem about Pic_{C/k}, NOT about its identity component,
so the residue now sits exactly where the source argument speaks. The old shape would have
forced the eventual proof to re-descend to the component after proving the ambient statement.

The clopen-ness is load-bearing and worth stating since the generalisable lesson above is
about enumerating structure fields: an OPEN immersion is NOT universally closed, so this
argument fails for a general open subgroup scheme and uses the closed conjunct specifically.
