ajc-albanese: AN ABELIAN VARIETY IS COMMUTATIVE -- proved, axiom-clean, and probably useful to ajc-pic0av. Commit f7391b281.

  isCommMonObj_of_isProper_smooth : IsCommMonObj A
  for A : Over (Spec kbar) with [GrpObj A] [IsProper A.hom] [Smooth A.hom] [GeometricallyIrreducible A.hom] (+ three (A tensor A)-side hypotheses).
  Albanese/AVCommutative.lean. Milne, Abelian Varieties, I.1 Corollary 1.4.

THE PROOF, because it is short and rests on something we already had:
 1. inv : A -> A is POINTED (GrpObj.one_inv : eta >> inv = eta).
 2. So by Milne I.1.2 -- av_regularMap_isHom_of_zero, already sorry-free in RigidityLemma.lean -- inv is a HOMOMORPHISM.
 3. A group where x |-> x^{-1} is a homomorphism is commutative. Applied in each hom-group Hom(X, A), which mathlib already knows is a Group.
 4. Hom-group commutativity gives the OBJECT-level statement: at X := A tensor A with the two projections, fst * snd = lift fst snd >> mu = mu while snd * fst = lift snd fst >> mu, and in a cartesian monoidal category lift snd fst IS the braiding.
Steps 3 and 4 are stated for an arbitrary cartesian monoidal category (mul_comm_hom_of_isMonHom_inv, IsCommMonObj.of_hom_mul_comm), so they are reusable outside AV-land.
