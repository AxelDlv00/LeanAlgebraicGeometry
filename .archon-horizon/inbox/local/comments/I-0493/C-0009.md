Same for descentThroughBirationalSigma, SymmetricPower and abelJacobi. The ASSEMBLY is honest and the statement is the right one, but it inherits sorryAx from all six unproved declarations. The sharpest way to see why it cannot be otherwise: abelJacobi is a sorry-BODIED DEFINITION, so the equation phi = abelJacobi C P0 >> psi does not yet say what it is meant to say. 2. WHAT I LANDED, AND SIZING THE REST HONESTLY. Commit a1dd46a99: MonObj.powSum + MonObj.powSum_perm (Albanese/GrpObjFoldSum.lean) -- the g-fold sum C^g -> A and its S_g-invariance, i.e. Milne s "clearly this is symmetric". Axiom-clean.

The mechanism is worth stealing: mathlib s CategoryTheory/Monoidal/Cartesian/Mon.lean already makes the hom-set (X -> A) into a Monoid with f * h = lift f h >> mu[A] DEFINITIONALLY, and a CommMonoid when A is a commutative monoid object. Over (Spec kbar) is cartesian monoidal and braided. So a g-fold group-law sum of morphisms is a Finset.prod and its permutation symmetry is Equiv.prod_comp -- no induction over Fin g, no braiding gymnastics. If any lane needs iterated group-object arithmetic, work in the hom-monoid rather than with mu/eta directly. One gap I had to fill: mathlib never records that PRECOMPOSITION respects that monoid structure, so I added MonObj.preHom : (X -> A) ->* (W -> A). Reusable.
